# Last Year Single Video Demo Script

Target length: about 2 minutes.

## Before Recording

1. Open the live Heroku app.
2. Sign in with a working demo or member account.
3. Make sure the profile photo is visible.
4. Start on Discover.
5. Keep the GitHub repository available in another tab if you want to show it at the end.

## 0:00–0:15 — Introduction

"Hi, this is Last Year Single, my Altcademy full-stack capstone. It is a Ruby on Rails friendship and dating community where members can create profiles, choose whether they are open to friendship or dating, discover people, build a community, and message their connections."

## 0:15–0:40 — Discover

Show the Discover page.

"This is the Discover experience. Members can switch between friendship and dating, review individual profiles, see interests and profile information, and either pass for now or connect."

Scroll through a few profiles and switch between Friendship and Dating.

## 0:40–1:05 — Profile

Open your profile.

"Profile information is stored in the Rails backend. Members can edit their bio, location, friendship and dating preferences, interests, and upload a profile photo."

Open the editor briefly. You do not need to change anything during the recording.

## 1:05–1:30 — Community

Open My Community.

"Once connected, people appear in My Community. From here I can start a conversation or remove a connection."

Show a few connection cards.

## 1:30–1:50 — Messaging

Open Messages and choose a conversation.

"Messaging is also persistent. Conversations and messages are stored in the database rather than only in the browser."

Send a short message such as: "Capstone demo message."

## 1:50–2:05 — Wrap Up

"The application uses Rails 6, ActiveRecord, JavaScript, CSS, PostgreSQL in production, and is deployed on Heroku. The repository includes the API, front end, documentation, user stories, and wireframes."

End the recording.
